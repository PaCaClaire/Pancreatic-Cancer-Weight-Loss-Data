# Pancreatic-Cancer-Weight-Loss-Data
This is the data extracted for the studies "Quantifying Weight Loss Prior to Pancreatic Cancer Diagnosis: A systematic review and meta-analysis" and "Comparing Weight Loss Prior to Pancreatic
Cancer Diagnosis in Cases and Controls: A Systematic Review and Meta-Analysis"

Data was extracted from studies eligible for inclusion in the systematic review and converted to two outcomes weight loss (kg) and BMI change. These outcomes correspond to the two files in this repository, with the third file containing data on weight loss for both cases and controls to allow a standardised mean difference comparison. 

For more information please see the associated publications.
